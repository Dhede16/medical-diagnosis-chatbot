# Template config.py untuk MedAI

Ini adalah template dari config.py. Gunakan untuk memperbaiki aplikasi jika ada error.

## LANGKAH 1: Dapatkan API Key

Pergi ke: https://console.groq.com

1. Login dengan akun Anda
2. Click Settings → API Keys (atau Sidebar → API Keys)
3. Click "Create New API Key"
4. Copy API Key 

## LANGKAH 2: Edit config.py

Buka file `config.py` dan cari baris ini:

```python
GROQ_API_KEY  = "API key"
```

Ganti dengan API Key Anda (dari Langkah 1):

```python
GROQ_API_KEY  = "PASTE_YOUR_API_KEY_HERE"
```

Contoh:
```python
GROQ_API_KEY  = "API key"
```

## LANGKAH 3: Save dan Test

1. Save file `config.py` (Ctrl+S)
2. Buka terminal dan jalankan: `python test_api.py`
3. Tunggu 30 detik untuk melihat hasilnya

Jika berhasil, akan muncul ✅ dan test message dari AI.

## LANGKAH 4: Restart Aplikasi

1. Tutup aplikasi (jika sedang berjalan)
2. Jalankan: `python main.py`
